# 🌦 IoT Based Weather Station  
### Embedded Systems Design (ESD) Assignment

## 📌 Project Overview

This project is a real-time IoT Weather Monitoring System developed using Arduino Nano, Firebase Realtime Database, and a live web dashboard hosted on GitHub Pages.

The system collects environmental data from sensors and displays it on a modern, interactive cloud-based dashboard.

---

## 🎯 Objective

The objective of this project is to design and implement a low-cost IoT-based weather station that can monitor environmental conditions in real time using cloud technology.

---

## 🏗 System Architecture

Sensors → Arduino Nano → Python Script → Firebase Cloud → GitHub Web Dashboard

---

## 🔧 Hardware Components

- Arduino Nano
- DHT11 Temperature & Humidity Sensor
- LDR (Light Sensor)
- Rain Sensor Module
- USB Communication Cable

---

## 💻 Software Technologies

- Python (Serial Communication + Firebase Admin SDK)
- Firebase Realtime Database
- HTML, CSS, JavaScript
- Chart.js for Graph Visualization
- GitHub Pages for Web Hosting

---

## ⚙ Working Principle

1. Sensors collect environmental data.
2. Arduino Nano reads sensor values.
3. Data is sent to the laptop via USB.
4. Python script uploads data to Firebase.
5. The web dashboard fetches live data from Firebase.
6. The dashboard updates graphs and animations in real time.

---

## 📊 Features

- 🌡 Real-time Temperature Monitoring
- 💧 Real-time Humidity Monitoring
- ☀ Automatic Light Detection (Bright/Dark Theme)
- 🌧 Rain Detection with Animation
- 📈 Separate Live Graphs for Temperature and Humidity
- 🌐 Cloud-Based Monitoring
